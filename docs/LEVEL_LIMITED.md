# 上场方向震荡区间内模拟

固定页面ID：`level-limited`，菜单副标题显示该ID。原名「上场方向（超出不下单）模拟」；只调整中文名称，路由、接口、账本与LP-001规则均沿用。「震荡区间」即下支撑位到上压力位的完整区间（含两端），蓝色中部只是其子区域。

入口 `/level-limited`，模拟报表有同名标签。策略版本 LP-001，新盘默认暂停，不启用实盘。

## 规则

沿用上场方向 PR-001：固定反买紧邻上一场市场方向；恰好连续两场同向时跳过一次，同一段持续走势只跳一次。官方结果优先，尚未结算可用同源预测；开盘15秒内每场最多一次，按本盘买价范围、tick、深度、最小份额、费用、资金和止损检查。

额外要求入场时的官方BTC价格满足 `支撑位 ≤ 当前价格 ≤ 压力位`。低于支撑或高于压力不下单，等于边界允许；完整区间均可下单，不要求处于中间蓝区。检测窗口内回到区间可以继续尝试；窗口结束后跳过本场。等待不计亏损，马丁轮次保留。

资金沿用纯翻倍：首笔可设，预计失利翻倍、预计获胜回首笔，超过单笔金额或加倍次数上限恢复首笔。已有持仓继续预测和结算。

## 独立配置与数据

首次仅复制原上场方向模拟的资金参数、支撑压力回看时间、蓝色比例和历史窗口滞后，不复制原账户余额、订单和日志。以配置的初始资金新建独立暂停账户。之后本盘首笔、单笔上限、加倍次数、止损、最低/最高买入价及区间参数分别保存，其他模拟和实盘不受修改影响。

支撑压力采用现有5分钟实体K线的历史极值，按本盘回看时间和首次复制的滞后分钟数计算。回看默认沿用来源（通常60分钟），最短15分钟、最长1440分钟，按5分钟调整。蓝色占比仅供图表。修改参数前须暂停本盘并等待持仓结算；后端也执行检查。

原始行情与官方起止价使用共享缓存，实时BTC和target复用现有连接。本盘专用 `ChartRange` 用独立设置计算上下界；前端通过 `/level-limited/api/events?chart=1` 一条SSE接收状态与独立生产的图表事件，图表和入场使用同一区间对象；隐藏标签页释放连接，返回时回放当前数据。开盘检查可同步做必要的本地计算，不等待上游请求；需要更长历史时由现有低优先级补数队列扩展范围，避开保护窗口。暂时未就绪可沿用紧邻上一场同口径区间并标记来源，跨两场或预言机变更不沿用；仍无有效区间则等待。

BTC报价须来自当前场共享官方流，采样不早于开盘、距今不超过6秒，且符合该场预言机窗口；最多接受2秒时钟超前。订单占用前再次检查，报价期间越界取消本次尝试。界面与拦截日志分别说明高于压力、低于支撑、报价过期、缺少本场报价、区间未就绪等具体原因及已知数值。

## 实现

- `server/level-limited-engine.mjs`：`LevelLimitedStore`、`LevelLimitedEngine`、`independentLevelRange`。
- `server/strategy-versions.mjs`：LP-001不可覆盖版本说明。
- `data/previous-level-limited.sqlite`：标准交易表；独立 `level_limit_settings`；逐单区间证据 `level_limit_order_signals`。
- `/level-limited/api/state/events/history/paper/*`：本盘交易状态、市场历史、分页、导出、隐藏、清空、重置及报表。
- `/level-limited/api/chart-settings`：独立图表/过滤区间设置；本机Origin与本页令牌验证。
- `/level-limited/api/events?chart=1`：状态及图表共用一条浏览器连接，共享价格和target，本盘独立支撑压力。旧 `/level-limited/api/chart-events` 保留兼容。

订单保存LP-001版本、交易配置编号、不可改写的下单原因及结构化区间/价格证据。隐藏与结算保留证据；清空已结束订单时删除对应证据，但同场占用记录保留。

验证：`node --test --test-isolation=none tests/level-limited.test.mjs tests/previous-direction-engine.test.mjs tests/chart-range.test.mjs tests/api.test.mjs tests/reports.test.mjs`，覆盖上下越界、精确边界、蓝区外仍可入场、报价后越界、原跳场与资金规则、设置持久化/隔离、API令牌/报表和历史补数扩展。
